Employee Time Management System

Files: Main.java, Employee.java, Schedule.java, WorkLog.java, TimeOffRequest.java, DataStore.java

Open the folder as a Java project in Eclipse. Put all six .java files in the same src folder (default package), then run Main.java.
HR login: choose option 1 and enter password 12345.

Do not add older versions of these same classes to the project, because that causes duplicate-class errors. Data is saved in employee_time_data.ser in the program working directory.
